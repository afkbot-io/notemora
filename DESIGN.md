# Интерфейс кабинета

Кабинет предназначен для разбора замечаний и управления доступом. Главная
поверхность — список обсуждений с выбранным сообщением и снимком, без декоративных
метрик. Проекты, участники и токены открываются отдельными разделами.

Палитра: бумага `#ffffff`, фон `#f5f7fb`, основной текст `#182438`, вторичный
`#64738b`, акцент `#315bdf`, успех `#187763`, ошибка `#b33b47`.
Шрифт — системный sans-serif с удобной кириллицей; 14–16 px основной текст,
28–32 px заголовок. Поля и кнопки имеют видимый focus, минимум 40 px высоты.

Левое меню сохраняет положение, правая область предназначена для контекста.
На узком экране меню становится верхним, детали открываются после списка.
Пустой раздел объясняет следующий шаг. Любые данные списка приходят из API.
SDK имеет собственный Shadow DOM и не импортирует Tailwind preflight в чужую страницу.

Виджет использует те же цвета и системный шрифт. Действия различаются контурными
SVG-иконками, счётчик сообщений отделён от подписи, активный режим выбора выделен
синим. Минимальная высота кнопки — 40 px; на телефоне поля имеют шрифт 16 px.
При выборе рамка с подписью следует за фактическим блоком под указателем и
совпадает с сохраняемой привязкой. Выбранный блок остаётся отмеченным при вводе.
«Показать блок» временно скрывает панель, прокручивает к блоку и выделяет его
на 3 секунды, затем возвращает обсуждение с черновиком. Escape возвращает его
сразу. При отключении, смене страницы или закрытии виджета временный показ
отменяется. Reduced motion оставляет рамку статичной без плавной прокрутки.

Вход — одна форма без рекламного блока. В кабинете нет вводных описаний разделов,
декоративных пиктограмм и eyebrow-строк. Техническое подключение раскрывается
только в настройках проекта/токенов. Срок хранения показывается один раз в шапке.
