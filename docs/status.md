# Состояние Notemora

Работают аккаунты и приглашения, проекты и роли, обсуждения со снимками, SDK
в Shadow DOM, кабинет, персональные токены и MCP stdio. Есть CLI для создания
пользователя и сброса пароля, поиск, пагинация и управление участниками.

SDK поддерживает выбор мышью, клавиатурой и касанием, предварительную подсветку,
переход к блоку, восстановление черновика и отмену при смене страницы.
API проверяет доступ к каждому объекту; сообщения живут семь суток.

Запуск — npm/uv/PostgreSQL или Docker Compose. Есть production override и Helm chart.
GitHub Actions проверяет исходники без доступа к production. Публикация SDK в npm
и готовые container images пока не настроены; доступны локальная сборка и SDK archive.

SHA/build сохраняются как переданный SDK контекст. Подтверждение через Git provider
API, сравнение версий, resolved-статусы и уведомления пока не реализованы.
Нет SMTP, SSO/MFA, самостоятельного восстановления пароля и HTTP/OAuth MCP endpoint.

DOM-снимок может отличаться для iframe, WebGL, внешних изображений и части CSS.
Приватный текст вне полей размечается `data-review-private`. Мобильные устройства
и реальный S3 проверяются отдельно в целевом окружении.
